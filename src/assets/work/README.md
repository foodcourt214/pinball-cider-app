# Case study imagery

Drop real images from the live site here, one folder per case study slug:

```
src/assets/work/bakerly/cover.jpg
src/assets/work/city-fish/cover.jpg
...
```

`cover.jpg` (also `.jpeg`, `.png`, or `.webp`) is picked up automatically and
replaces the placeholder art in the work grid and on the case study page.
